# Badges

Badge images and assets for contributor recognition. See the main README for the full list of tiers and specialty badges.

- `cards/` — the official badge cards (badge, level, name and description), shown in the main README
- `*.png` — the badge on its own (512×512), for GitHub profile READMEs and avatars
- `svg/` — the same badges as SVG, generated by `scripts/make_badges.py`
- `share-card-template.jpg` — the wide "[YOUR NAME] earned the…" card for LinkedIn and X
