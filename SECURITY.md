# Security Policy

## Reporting issues with this repository

If you find a problem with the content in this repository (broken links,
inaccurate information, unsafe examples, or content that violates our safety
rules), please email **damilolaabiona8@gmail.com** or open a
[Bug/broken content](../../issues/new/choose) issue.

## Real product vulnerabilities

This repository contains **educational security content only**. If you discover
a real vulnerability in a real product or service, **do not open a pull request
or issue here**. Instead, report it directly to the affected vendor through
their responsible disclosure or bug bounty program.

Resources for responsible disclosure:

- [HackerOne Directory](https://hackerone.com/directory)
- [Bugcrowd Programs](https://www.bugcrowd.com/bug-bounty-list/)
- Look for a `SECURITY.md` or `/.well-known/security.txt` on the vendor's site

## Scope

This policy covers the CyberSecTOBER repository and its content. It does not
cover any external tools, labs, or services linked from this repository.
