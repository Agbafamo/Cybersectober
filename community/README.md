# Africa & Local Communities Track

Translations, localized guides, and resources for traders, SMEs, schools and communities across Africa.

**Subfolders:**
- `nigeria/`, `ghana/`, `kenya/` — country-specific guides and resources
- `translations/` — security content translated into Yoruba, Igbo, Hausa, Pidgin and Swahili

**How to contribute:** Translate existing guides, write localized security tips, or create resources for specific audiences (market traders, school students, small business owners). Copy a template from `templates/` to get started.
