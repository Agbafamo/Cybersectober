# Web & API Security Track

Guides, checklists, labs and tools for securing web applications and APIs.

**Topics:** OWASP API Top 10, BOLA, broken authentication, JWT security, rate limiting, input validation, CORS, API gateway hardening.

**How to contribute:** Write a guide, build a deliberately vulnerable lab, create a security checklist, or develop a tool. Copy a template from `templates/` to get started.
